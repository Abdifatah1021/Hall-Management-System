# Hall Management System

A web app for booking lecture and event halls, built with Python and Flask.

## Features
- Browse available halls with capacity, location and price
- (more features will be added as the project grows)

## Tech stack
Python, Flask, HTML, CSS (database and payments coming soon)

## Run it locally
1. Clone the repo: `git clone https://github.com/YOUR-USERNAME/hall-management-system.git`
2. Create a virtual environment: `python -m venv venv`
3. Activate it (Windows): `venv\Scripts\activate`
4. Install packages: `pip install -r requirements.txt`
5. Start the app: `python app.py`
6. Open http://127.0.0.1:5000
